# Everlight Garden art

The site's artwork is the pixel set in `px/` (see `px/LICENSE.md`, CC0 1.0). The earlier painted/realistic
sprites (`*.webp`, vector `candle-*.svg`) were retired on 2026-11-19 when the approved 16-bit pixel reference
replaced all earlier designs; they remain in Git history only. `og.png` is the share image.
